# DDInter data bundle

These CSV files were downloaded from https://ddinter.scbdd.com/download/ on 2026-07-15 for this non-commercial academic prototype.

DDInter data is licensed under CC BY-NC-SA 4.0. See https://ddinter.scbdd.com/terms/ and cite the DDInter publication when presenting or distributing derived work.

DDInter explicitly states that its data may be incomplete and that absence of a listed interaction does not prove that a combination is safe. MediFlow therefore presents these records as pharmacist-reviewed indicators, not automated clinical decisions.
